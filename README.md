HTTP codes

400 - שגיאה בגוף הבקשה, אחד הערכים לא נכון או לא קיים

404 - ההתראה המבוקשת לא קיימת

500 - בעייה לא צפויה בשרת

---

הולידציה בודקת שהערכים שהתקבלו תאומים למבוקש: טקסט פשוט או מספר או בחירה מתוך רשימת אפשרויות
